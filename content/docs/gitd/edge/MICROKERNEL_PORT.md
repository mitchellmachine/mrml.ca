# Microkernel port boundary

The reusable protocol, renderer, and in-memory cache are no-std friendly. A
future service receives explicit UDP, time, randomness, cache, certificate-use,
and backend capabilities. Repository names and connection IDs never authorize.
Secret use and export remain separate.

The port is **PLANNED**. No MRML service manifest, capability wiring, native
network execution, or physical-network evidence exists.
